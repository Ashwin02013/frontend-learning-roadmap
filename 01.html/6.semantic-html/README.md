
semantic.html

- Semantic tags describe the MEANING of each part, not just the look
- Better for SEO, screen readers and for other developers reading the code
- Replaces a pile of meaningless <div> tags



SEMANTIC PAGE = A NEWSPAPER

│
├── <header>   → Newspaper name and masthead on top
├── <nav>      → Index / contents strip (Sports, Business, Cinema)
├── <main>     → The main news area
│   ├── <section> → One whole page (Sports page)
│   ├── <article> → One single news story
│   └── <aside>   → Side box (advertisement / related links)
└── <footer>   → Printing details, contact, copyright at the bottom
