- Tags change HOW the text looks or what it MEANS
- <b> / <i> only change the look, <strong> / <em> also tell the browser "this is important"
- Use <sub> and <sup> for formulas like H2O and X squared



TEXT FORMATTING = A SCHOOL NOTEBOOK

│
├── <h1>–<h6>   → Chapter title → sub-heading (big to small)
├── <p>         → A normal paragraph of notes
├── <b>/<strong>→ Writing in thick pen (important point)
├── <i>/<em>    → Slanted handwriting (stress a word)
├── <u>         → Underline with a ruler
├── <small>     → Tiny footnote
├── <mark>      → Yellow highlighter
├── <del>/<ins> → Cut a word with a red pen / write a new word in
└── <sub>/<sup> → Chemistry (H2O) and maths (X squared) tiny numbers
