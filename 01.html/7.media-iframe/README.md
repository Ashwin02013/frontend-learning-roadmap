
media.html

- <audio> and <video> play files; "controls" shows play/pause/volume buttons
- <source> lets you give a file and its type (browser picks one it supports)
- <iframe> shows ANOTHER webpage inside your page (YouTube, Maps)
- Text between the tags is a fallback for very old browsers



MEDIA = A HOME THEATRE

│
├── <audio>   → Music system
├── <video>   → TV screen
├── controls  → The remote (play, pause, volume)
├── <source>  → The disc / pen-drive you plug in
└── <iframe>  → A window in your wall showing someone else's room
    ├── YouTube embed → Window to a cinema
    └── Map embed     → Window to a city map
