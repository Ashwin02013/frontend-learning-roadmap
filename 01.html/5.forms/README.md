
form.html

- <form> collects data from the visitor and sends it somewhere
- <input type="..."> changes by type: text, email, password, tel, radio, checkbox
- Radio buttons share the same name so only ONE can be picked
- <label for="id"> is linked to the input with the same id (click label = focus input)



FORM = A PAPER APPLICATION FORM

│
├── <form>        → The whole paper
├── <label>       → Printed question ("Name:")
├── <input text>  → Blank line to write on
├── radio         → Tick ONE box (Male / Female)
├── checkbox      → Tick MANY boxes (Skills)
├── <select>      → Dropdown list of choices
├── <textarea>    → Big blank area for comments
└── submit/reset  → Hand the paper in / Erase everything
