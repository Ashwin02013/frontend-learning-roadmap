
listtable.html

- <ol> = numbered list (order matters), <ul> = bullet list (order doesn't matter)
- A list inside a list is a nested list
- Table = <table> > <tr> rows > <th> heading cells / <td> data cells
- colspan joins cells side by side



LISTS AND TABLES = SHOPPING + TIMETABLE

│
├── <ol>     → Recipe steps (1, 2, 3 - order matters)
├── <ul>     → Shopping list (just items)
├── nested   → Shopping list with sub-items (Fruits > Apple, Banana)
└── <table>  → School timetable
    ├── <tr>  → One row
    ├── <th>  → Header cell (Day, Period)
    └── <td>  → Normal cell
