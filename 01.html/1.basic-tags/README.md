- Every webpage is a text file ending in .html
- The browser always reads it top to bottom and builds the page 
- The basic structure is fixed that every page has it(on clicking ! and tab we can fetch the skeleton)





basic page.html

WEBSITE = A BUILDING
│
├── <!DOCTYPE html>  → Building code / rulebook ("follow modern rules")
│
└── <html>           → The whole plot of land and building
    │
    ├── <head>       → Office files & paperwork (not visible to visitors)
    │   ├── <title>  → Name board shown on the entrance (browser tab)
    │   └── meta     → Registration papers (language, encoding)
    │
    └── <body>       → The rooms visitors walk into
        ├── <h1>–<h6> → Signboards (big hall sign → small door label)
        ├── <p>       → Notice-board text
        └── <!-- -->  → Sticky notes engineers leave on the walls (visitors never see them)
