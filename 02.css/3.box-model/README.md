
index.html + style.css

- Every element is a rectangular box: content > padding > border > margin
- width and height only set the CONTENT by default (content-box)
- box-sizing: border-box makes width include padding + border (easier maths)



BOX MODEL = A GIFT BOX

│
├── content  → The gift itself
├── padding  → Bubble wrap around the gift
├── border   → The cardboard box wall
├── margin   → Empty space between this box and the next box on the shelf
└── box-sizing: border-box → "The size on the label is the FULL box size"
