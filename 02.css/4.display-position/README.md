
index.html + style.css

- display: block (new line, full width), inline (same line), inline-block (same line + width/height), none (hidden)
- position: relative (move from own place), absolute (relative to nearest positioned parent),
  fixed (stuck to the screen), sticky (normal until you scroll, then sticks)



DISPLAY AND POSITION = A CLASSROOM

│
├── block         → Each student has a full bench row
├── inline        → Students sit side by side in a line
├── inline-block  → Side by side but each has own desk size
├── none          → Student is absent
│
├── relative      → Student shifts a little from own seat
├── absolute      → Sits exactly at a spot measured from the classroom corner
├── fixed         → Poster stuck on the screen glass (never moves)
└── sticky        → Notice slides along, then sticks to the top of the board
