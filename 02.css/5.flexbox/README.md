- display: flex on the PARENT arranges the children in a row
- justify-content = along the main axis (left to right), align-items = the other axis (top to bottom)
- gap = space between items, flex: 1 = every item takes equal share
- Centering anything: display flex + justify-content center + align-items center



FLEXBOX = PEOPLE STANDING ON A BENCH

│
├── display: flex       → "Everyone sit in one row"
├── justify-content     → How they spread on the bench (space-between = far apart)
├── align-items         → Whether they sit at top, middle or bottom of the seat
├── gap                 → Elbow space between people
├── flex: 1             → Everyone gets an equal width of the bench
└── Real use            → Navbar (logo left, links right), card rows, centered login box
