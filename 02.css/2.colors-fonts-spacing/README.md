- color = text color, background-color = behind the text
- font-family (with fallbacks), font-size, line-height (gap between lines)

COLORS, FONTS, SPACING = DECORATING A ROOM

│
├── color / background → Paint on the wall and the furniture
├── font-family/size   → Style and size of the nameplate
├── line-height        → Gap between rows of books on a shelf
├── padding            → Cushion inside a photo frame
├── border             → The frame itself
└── margin             → Empty space between two frames on the wall
