
index.html + style.css

- 3 ways to add CSS: inline (style=""), internal (<style>), external (style.css)
- External is the best: one file styles many pages
- Selectors: element (p), class (.name), id (#name), group (h2, h3)
- Priority: inline > id > class > element



CSS LINKING AND SELECTORS = A SCHOOL UNIFORM RULE

│
├── Inline    → Principal tells ONE student personally
├── Internal  → Class teacher rule for ONE class
├── External  → School rulebook for ALL classes
│
├── element   → "All students" (p)
├── .class    → "All students in Group A" (.highlight)
├── #id       → "Roll no. 5 only" (#main-title)
└── group     → "Group A and Group B together" (h2, h3)
